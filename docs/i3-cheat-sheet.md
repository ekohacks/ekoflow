# i3 Cheat Sheet

Print this and keep it next to your keyboard. **Super** is the key with the Windows logo, between Ctrl and Alt. Every command below starts with it.

---

## Windows

| Keys | What happens |
|------|--------------|
| `Super+Enter` | Open a terminal |
| `Super+d` | App launcher (type a name, press Enter) |
| `Super+Shift+q` | Close the current window |
| `Super+f` | Fullscreen on and off |
| `Super+h/j/k/l` | Focus window left, down, up, right |
| `Super+Shift+h/j/k/l` | Move window left, down, up, right |
| `Super+v` / `Super+b` | Next window opens below / beside |

The focus keys are the same `h` `j` `k` `l` you use in Neovim. One dialect, everywhere.

---

## Workspaces

Each workspace is a separate screen. The dojo names them by activity.

| Keys | Where you go |
|------|--------------|
| `Super+1` | 1: code |
| `Super+2` | 2: test |
| `Super+3` | 3: git |
| `Super+4` | 4: web (Firefox lives here) |
| `Super+Shift+1/2/3/4` | Send the current window there |

---

## Resizing

| Keys | What happens |
|------|--------------|
| `Super+r` | Enter resize mode |
| `h` `j` `k` `l` | Shrink or grow the window |
| `Enter` or `Esc` | Back to normal |

---

## Machine Keys

| Keys | What happens |
|------|--------------|
| Volume keys | Louder, quieter, mute |
| Brightness keys | Screen brighter or dimmer |
| `Super+Shift+x` | Lock the screen |
| `Super+Shift+r` | Restart i3 (keeps your windows) |
| `Super+Shift+e` | Exit i3 (asks first) |

---

## When You Are Stuck

A window vanished? It is probably on another workspace. Walk through `Super+1` to `Super+4` and you will find it.

Everything frozen? `Super+Shift+r` restarts i3 and your windows survive.

The screen cannot be broken by pressing keys. The worst case is restarting i3, which takes one second.
